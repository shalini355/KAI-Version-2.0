# Security Policy

## Supported versions

This project is currently in active development. Security updates are handled on a best-effort basis.

## Reporting a vulnerability

Please do not disclose security issues publicly.

Instead, contact the maintainer privately through the project’s GitHub security reporting channel or by emailing the repository owner directly.

Include:

- a description of the issue
- affected files or endpoints
- reproduction steps
- severity and impact assessment

## Response expectations

We will review valid reports as quickly as possible and work toward a fix with a reasonable timeline.
